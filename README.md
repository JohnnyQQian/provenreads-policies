# ProvenReads policies

Public privacy and account-deletion pages. Contains no app/backend source or credentials.

## Publish

1. Create the public GitHub repository `JohnnyQQian/provenreads-policies`.
2. Upload these files to the root of branch `main` (not inside a second folder).
3. Settings > Pages > Build and deployment > Source: Deploy from a branch.
4. Branch: main. Folder: /(root). Save. Wait for Pages deployment to succeed.
5. Open the URLs below and check the links and support email.

- https://johnnyqqian.github.io/provenreads-policies/privacy.html
- https://johnnyqqian.github.io/provenreads-policies/account-deletion.html

The app still links to the original Render pages until its links are updated after this site is verified.
Edit the HTML text directly to make future wording changes; no Python or build tooling is required.
Both pages reflect the wording approved on 15 October 2026.
